## ⚡ Key Philosophy

We believe AI interfaces should be as intuitive as Apple hardware. This skill isn't just a utility; it’s an extension of Manus's cognitive capability, built with three core principles:

*   **Zero Overhead:** Lightweight architecture with minimal latency.
*   **Adaptive Intelligence:** Context-aware execution that evolves with your prompts.
*   **Predictable Outcomes:** Strict type-safety and error-handling patterns.
